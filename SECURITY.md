# Security policy

This is the default security policy for Drums-Labs repositories that do not have their own. drumsd,
drums-python-sdk, drums-verifiers and drums-criu each have their own SECURITY.md, which takes precedence.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

1. Preferred: GitHub private vulnerability reporting, from the repository's **Security** tab ("Report a
   vulnerability").
2. Email: security@drums.run.

Say which repository and version or commit, what you found, and how to reproduce it. We acknowledge a report
within 3 business days, as the repositories' own policies say, and agree the disclosure timing with you.
